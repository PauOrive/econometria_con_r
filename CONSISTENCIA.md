# Notas sobre consistencia

En este documento apunto de forma relativamente desordenada cuestiones de consistencia de estilo para revisar una vez tenga listo la mayor parte del contenido. 

* Al principio empecé nombrando los objetos con un prefijo (eg. tb_ para tibbles, df_ para data.frames, dt_ para data.table). Pero luego he dejado ese estilo, y creo que lo voy a abandonar.
* En los chunks de R tengo qué pensar qué cuestiones quiero definir con #| al principio (label seguro, aunque quizás merece la pena añadir un código inicial, tipo num capítulo + letra, o + letra + número cuando sea un tabset). Quizás también merece la pena introducir texto alternativo, fig-cap y demás.
